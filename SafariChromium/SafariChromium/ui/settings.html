Targets are best-effort. When over the RAM target, Safari may hibernate background tabs; they reload when reopened, so unsaved page state can be lost. Electron cannot impose a hard CPU limit on active websites.

Advanced Controls

Passwords

Passwords are encrypted with your operating-system credentials on this device.

Export passwords as a CSV from Chrome or Edge, then import that file here. Imported passwords are stored in the encrypted local vault.

Passkeys

On supported HTTPS sites, passkeys use Chromium WebAuthn and Windows Hello or a security key. Create and manage them in the site's account settings; passkey private keys stay in the Windows credential provider.
